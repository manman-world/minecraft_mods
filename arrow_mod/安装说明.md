# 飞机模组安装与使用说明

本项目也已接入支持发射和空中爆炸的方块火箭，获取、点火和默认参数见 [火箭使用说明](火箭使用说明.md)。飞机功能仍然保留。

适用：Minecraft **Java 版 26.2**，NeoForge **26.2.0.82**。不适用于基岩版、Fabric 或旧版 Minecraft。

## 一、安装游戏模组

1. 在 Minecraft 启动器中安装并启动一次 Java 版 26.2，然后退出游戏。
2. 双击本项目的 `install-neoforge.cmd`，使用已下载的官方 **26.2.0.82** 安装器，选择安装客户端（Install client），指向你的游戏目录。
3. 在启动器中选择安装好的 NeoForge 26.2 配置，启动一次，再退出。
4. 将本项目 `build/libs/skyplanes-1.0.0.jar` 放进该配置游戏目录的 `mods` 文件夹。没有这个文件夹就新建。默认目录通常是 `%APPDATA%\.minecraft\mods`；如果启动器启用了版本隔离，应使用该配置自己的游戏目录。
5. 重新启动 NeoForge 配置，在模组列表里确认出现 **Sky Planes**。

注意：只有构建成功后才会生成上述模组文件。安装器的 JAR 和飞机模组的 JAR 是两个不同的文件，不要把安装器放进 mods。

安装器官方网站：https://projects.neoforged.net/neoforged/neoforge 。安装脚本使用项目中的 Java 25，不要求 Windows 已关联 JAR 文件。

## 二、第一次试飞

1. 新建一个创造模式测试世界，找一块宽阔平地。
2. 在创造物品栏“工具与实用物品”中找到“飞机组装包”，或开启作弊后输入 `/give @s skyplanes:plane_kit`。
3. 手持组装包，对平地右键放置飞机；空手右键飞机上机。
4. 建议按 F5 切到第三人称。按住 W 加速，稍微向上看即可起飞。
5. 鼠标左右看控制转向；向上看爬升，向下看下降。S 减速。
6. 降落时轻微向下看，接近地面后按 S 减速；停稳再按 Shift 下机。
7. 没有人乘坐时，左键攻击飞机可收回组装包。

这是第一版轻型飞机，暂未提供合成配方、燃料、复杂仪表和损伤系统。空中下机仍可能摔落，请在地面下机。

## 三、开发环境（已下载到本项目）

- Java 开发环境：`.tools/java` 中的 Temurin JDK 25。
- 构建工具：项目自带 Gradle Wrapper，版本 9.2.1。
- NeoForge：26.2.0.82，由官方 Minecraft 26.2 模板配置。
- `build-mod.ps1`：使用本项目 Java 编译模组。
- `play-dev.ps1`：启动开发测试客户端。

双击 `build-mod.cmd` 编译，双击 `play-dev.cmd` 启动开发测试客户端。也可以在本文件夹的 PowerShell 中运行对应的 `.ps1` 脚本。首次构建和首次启动需要联网下载依赖。无需修改系统 Java 配置。

## 四、常见问题

- **模组不出现**：检查游戏是否选择 NeoForge 26.2，文件是否放入当前配置的 mods 文件夹。
- **版本不兼容**：核对 Minecraft 为 26.2、NeoForge 为 26.2.0.82。
- **找不到 Java**：使用本项目提供的脚本，它会选择 `.tools/java` 中的 Java 25。
- **放不出飞机**：选择空旷平地，给飞机留出空间。
