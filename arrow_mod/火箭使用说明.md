# 方块火箭：发射与空中爆炸

本版在现有 **Sky Planes** 模组内加入火箭点火、垂直升空和空中爆炸，飞机功能仍然保留。构建配置为 Minecraft **Java 26.2**、NeoForge **26.2.0.82**、Java **25**。

## 安装与获取

1. 运行 `build-mod.cmd`，构建成功后使用 `build/libs/skyplanes-1.0.0.jar`。
2. 退出游戏，把此 JAR 放入对应 NeoForge 游戏配置的 `mods` 目录。如果已装旧版 Sky Planes，请用新文件替换，避免同时安装两份。
3. 启动游戏，在创造物品栏的“工具与实用物品”找到“火箭组装包”，或启用作弊后输入：

   `/give @s skyplanes:rocket_kit`

## 放置与回收

- 手持火箭组装包，对坚实完整地面的顶面右键放置。建议准备至少 **3×3 格平地、4 格净空**，并站在放置位置旁边。
- 火箭模型约宽 **1.625 格**、高 **3.25 格**。空间有方块或实体阻挡时不会放置，也不会消耗组装包。
- 生存模式放置消耗一个组装包。**尚未点火**时，左键打掉火箭可回收组装包；创造模式放置不消耗，打掉不额外掉落。
- 未点火火箭保持静止，可阻挡移动。移除地面不会让它自动掉落。

## 点火、升空与爆炸

1. 在露天平地放置火箭，上方应保留至少 **28 格无障碍空间**，以便完成正常升空。
2. 切换到空的快捷栏格子，**主手空手右键火箭**点火。不要按住 Shift；冒险模式和旁观模式不能点火。
3. 出现点火提示后退开。火箭倒计时 **3 秒**，有烟雾和每秒提示音，随后垂直上升，带有尾焰、烟雾与发射音效。
4. 火箭底部相对点火位置升高 **24 格**，或升空后的飞行时间达到 **5 秒**时，触发空中爆炸并消失。两个条件先满足者生效。

| 参数 | 默认值 |
| --- | --- |
| 点火倒计时 | 60 游戏刻，正常 20 TPS 时为 3 秒 |
| 飞行最长时间 | 100 游戏刻，正常 20 TPS 时为 5 秒 |
| 爆炸相对高度 | 火箭底部升高 24 格 |
| 向上速度 | 基础 0.15 格/刻，每飞行刻增加 0.035，最高 0.8 格/刻（16 格/秒） |
| 爆炸强度 | 3.0，原版爆炸伤害与击退 |
| 地形影响 | 不破坏方块，不产生火焰方块 |
| 最低爆炸高度 | 相对点火位置升高至少 6 格 |

爆炸中心在火箭中部。附近玩家、生物等实体可能受到伤害和击退，创造模式等原版免伤规则仍然适用。服务端低 TPS 时倒计时和飞行的现实时间会相应变长。

## 防重复操作与异常处理

- 点火后不能取消、再次点火或通过攻击回收；爆炸和熄火都不掉落组装包，不产生重复物品。
- 倒计时或上升路径遇到方块、可碰撞实体或世界边界阻挡时，火箭冒烟熄火并消失，**不爆炸、不退款**。
- 接近世界建筑高度上限时结束飞行：已经上升至少 6 格可爆炸，否则熄火。障碍检查优先，受阻时始终熄火。
- 飞行超时但高度不足 6 格时同样熄火，不在发射台附近爆炸。
- 状态、剩余倒计时、飞行刻数及点火高度随实体存档保存。退出世界或区块卸载期间暂停，重新加载后继续，不重新开始计时。
- 旧版未点火静态火箭可以正常点火。无效或损坏的发射状态会作为已消耗火箭移除，避免变回可回收物品。
- 点火、移动、粒子、音效和爆炸由服务端处理；客户端同步状态并平滑显示位置。多人同服应安装同一版本模组。
- 本版仍无合成配方、驾驶、燃料系统或自定义参数界面。

## 模型来源与维护

原模型为 `blender_3D/arrow.blend`，导出不会修改它。27 个长方体转换为 Minecraft 实体模型，五种材质转换为像素纹理，另有独立物品栏图标。源模型的 Z 向上坐标转换为 Minecraft 模型的 Y 轴，1 Blender 单位对应 1 游戏格。

已有 Blender 时可重新导出：用 Blender 后台打开源文件并执行 `tools/export_rocket.py`。脚本生成 `RocketGeometry.java`、两张 PNG 和 `blender_3D/rocket-export.json`；JSON 记录源文件哈希、各零件尺寸与材质。仅支持当前这类无修改器的轴对齐长方体模型。
